# Чернильник

Личный Telegram-бот — литературный соавтор для текстовых ролевых игр.

Художественный текст генерируется через **Polza** (по умолчанию Gemini Flash) или OpenAI. Память и анализ фото всегда идут через **OpenAI**. Стек: Python 3.11+, aiogram 3, SQLite.

Только владелец (`OWNER_TELEGRAM_ID`), только личный чат. Перегенерации и выбора «следующего события» нет: обычное сообщение в начатой истории — это ход.

## Как пользоваться

1. Напиши «хочу новую историю» или `/new`.
2. Бот спросит мир, выслушает идею, примет описание героев и портреты.
3. Скажи **«погнали»** — создастся история и начнётся первый пост.
4. Дальше пиши ходы обычными сообщениями.

Все настройки — в `/menu` (inline-кнопки). Постоянной нижней клавиатуры нет; если она осталась от старой версии — `/hidekeyboard`.

### Команды

| Команда | Назначение |
|---|---|
| `/new` | Разговорная подготовка новой истории |
| `/worlds` | Миры, канон, энциклопедия, жители |
| `/sessions` | Список и выбор историй |
| `/menu` | Настройки: персонажи, сцена, память, стиль, модель… |
| `/model` | Модель генерации текста |
| `/backup` | Скачать копию SQLite |
| `/cancelsetup` | Отменить подготовку |
| `/help` | Справка |
| `/id` | Показать свой Telegram ID (без проверки владельца) |

Также есть: `/begin`, `/last`, `/opening`, `/export`, `/draft` + `/play` + `/cancel`, `/status`, `/prompt`, `/remember`, `/memory`, `/switch`, `/world`, `/cast`, `/time`, `/location`, `/setup`.

### Миры и персонажи

- **Мир** — канон, энциклопедия (страны/места), хроника событий, библиотека жителей.
- **История** — сюжет в мире или свободная; свои ходы, время, локация, факты.
- **Персонаж** — карточка из библиотеки мира; в разных историях — разные роли (игрок / бот / NPC) и разный пережитый опыт.
- **Анкета** — необязательные поля (основное, биография, психология, отношения); авторские записи и сюжетные наблюдения не смешиваются.
- Канон и статьи можно прислать текстом или UTF-8 `.txt` / `.md`. Есть ИИ-импорт библии через Polza (черновик → подтверждение).

### Генерация и память

- Пока модель пишет, Telegram показывает «печатает…» (обновление раз в ~4 с).
- После сохранения хода OpenAI может извлечь факты истории, подтверждённые мировые события и наблюдения по персонажам (`AUTO_MEMORY`).
- Стиль и примеры постов настраиваются в `/menu` → «Стиль и примеры»; пустые примеры не подменяются скрытыми образцами.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
python bot.py
pytest   # опционально
```

Минимум в `.env`: `BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `OPENAI_API_KEY`. Для Polza — ещё `POLZA_API_KEY`.

### BotHost Pro

1. Репозиторий в корень проекта; точка входа `bot.py` (`bothost.json`, Python 3.11).
2. `DATABASE_PATH=/app/data/roleplay.sqlite3`, каталог `/app/data` — постоянный.
3. Не удаляй `/app/data` при обновлениях. Перед обновлением: `/backup`, при необходимости сохрани `portraits/`.
4. Новую пустую БД создавай только осознанно: `ALLOW_NEW_DATABASE=true` на один запуск, затем убери флаг. На BotHost без файла БД и без этого флага бот **не стартует** (чтобы не затереть истории новой пустой базой).

### Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `BOT_TOKEN` | — | токен бота |
| `OWNER_TELEGRAM_ID` | — | числовой ID владельца |
| `OPENAI_API_KEY` | — | память и vision |
| `POLZA_API_KEY` | — | генерация через Polza, импорт библии |
| `DATABASE_PATH` | локально `roleplay.sqlite3` | путь к SQLite |
| `ALLOW_NEW_DATABASE` | выкл. | разрешить создать пустую БД |
| `MEDIA_DIR` | `<рядом с БД>/portraits` | фото персонажей |
| `OPENAI_MODEL` | `gpt-6-luna` | если генерация через OpenAI |
| `MEMORY_MODEL` | `gpt-6-luna` | извлечение памяти |
| `VISION_MODEL` | `gpt-6-luna` | анализ портретов |
| `GENERATION_PROVIDER` | `polza` | `polza` или `openai` |
| `GENERATION_MODEL` | `google/gemini-3.7-flash` | модель Polza |
| `POLZA_BASE_URL` | `https://polza.ai/api/v1` | endpoint Polza |
| `AUTO_MEMORY` | `true` | автоизвлечение после хода |
| `MAX_OUTPUT_TOKENS` | `1800` | лимит ответа |
| `PROMPT_DEBUG` | `true` | сохранять промпт для `/prompt` |

Выбор модели также хранится в `generation_model.json` рядом с БД (не ключи). Не коммить `.env`, токены и базу в Git.

## Ограничения

- Автопамять — это извлечение по ходам, не полный профиль с нуля. Предположения отделены от фактов.
- Глобальные события мира попадают в хронику только как подтверждённые; иногда сверяй вручную.
- Знания NPC ограничиваются промптом, не жёсткими ACL в БД.
- `/backup` — только SQLite; портреты лежат в `MEDIA_DIR`.
- Если пост уже в БД, а Telegram не доставил сообщение — смотри `/last` или `/opening`.
- При проблемах с путём к базе: [`DB_RECOVERY.md`](DB_RECOVERY.md).
