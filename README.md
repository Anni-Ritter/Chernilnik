# Личный литературный Telegram-соавтор (MVP 0.1)

**Статус:** исполняемый прототип для локального запуска. Живой запрос к OpenAI и Telegram не проверялся — нужны твои собственные API-ключи. Автопамять не гарантирует абсолютной непротиворечивости.

## Старт

1. Создай нового бота через [@BotFather](https://t.me/BotFather), возьми токен.
2. Уточни свой числовой Telegram ID (например, в сервисном боте, который показывает ID; либо временно запусти с любым числом и напиши /id своему боту).
3. Установи Python 3.11+.
4. В папке проекта создай `.env`, скопировав `.env.example`, вставь `BOT_TOKEN`, `OPENAI_API_KEY`, `OWNER_TELEGRAM_ID`.
5. Установи зависимости и запусти:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   python bot.py
   ```
6. Открой личный диалог с ботом в Telegram. `/start`, `/new История`, `/cast Я играю за ..., бот за ...`, и отправь стартовый пост.

## Долговременная память

- Полная история каждого хода навсегда сохраняется в локальной SQLite (`roleplay.sqlite3`), пока ты сама не удалишь БД. Сделай резервные копии файла.
- На каждом ходе модель видит последние 8 ходов, зафиксированное описание мира, роли, время, локацию и выборку важных фактов. Полная история **не** отправляется целиком в каждом запросе.
- Дополнительный вызов модели извлекает до 6 атомарных фактов с дословными свидетельствами в только что сыгранном ходе. Без точной цитаты автоматический факт не сохраняется. Выборка не сохраняет очевидный декоративный мусор (приоритеты ниже 3) и отделяет субъективные догадки от подтверждённых сведений.
- Факты с важностью 5 доступны глобально в пределах истории, остальные подтягиваются по пересечению ключевых слов. Это **упрощённая лексическая выдача**, без эмбеддингов/векторного поиска. Если важнейших фактов накапливается больше доступного бюджета контекста, некоторые из них тоже могут не попасть в конкретный запрос.
- `/remember` — вручную закрепить критический факт 5/5. `/memory` — проверить, что запомнено. Автоматическое извлечение может ошибаться: проверяй ключевые события.
- `/time` хранит текстовую временную опору. **Бот не отсчитывает дни и месяцы автоматически**: 10 постов не равны 10 дням. Для временных прыжков явно обозначай их в постах и обновляй `/time`. Полноценный фэнтезийный календарь пока не реализован.
- Все миры независимы — факты не мигрируют между сессиями.

## Важные ограничения первой версии

- Нет перегенерации, выбора ответов и кнопки подтверждения. Успешный ответ сразу записывается как очередной ход.
- Нет защиты от стопроцентных логических ошибок, перехвата персонажей и путаницы имён — пока это инструкции, а не гарантии. Сложный граф событий и строгая проверка канона — следующие этапы.
- Код не проверялся на реальном API (ключей нет), поэтому при несовместимости модели поправь `OPENAI_MODEL`/`MEMORY_MODEL`.
- Модельный вызов памяти добавляет цену к каждому ходу. `AUTO_MEMORY=false` отключает автопамять (ручные `/remember` продолжают работать).
- Указан `store=False` в OpenAI API, но запросы всё равно обрабатываются провайдером; изучи его условия хранения и приватности.
- Локальная БД не зашифрована. Не публикуй её и не коммить `.env` в Git.
- В `/status` отдельно учитываются токены генерации и памяти. Текущей долларовой оценки расходов пока нет.
- Подход к темам для взрослых определяется также ограничениями модели/провайдера; программно снять их нельзя.

## Управление

`/help` — список команд. `/draft` + сообщения + `/play` для поста длиннее лимита Telegram. `/export` отправит весь текст текущей истории как `.md`. `/last` повторно покажет последний сгенерированный ответ, если произошёл сбой отправки: **это не перегенерация**.

## Тесты

```bash
pytest -q
```

При тестах ни OpenAI, ни Telegram не вызываются. Проверяются SQLite, изоляция историй, выбор воспоминаний и фильтр свидетельств.
