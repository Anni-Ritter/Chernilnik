# Чернильник v0.4 — личный литературный соавтор для Telegram

aiogram 3 + OpenAI Responses API + SQLite. Одиночный пользователь, независимые сюжетные сессии, карточки персонажей, фото-референсы, автоматическая структурированная память и поиск старых постов.

**ВНИМАНИЕ! Обновляешь существующего бота на BotHost? Прочитай [`MIGRATION_v04.md`](MIGRATION_v04.md) перед деплоем. Не удаляй `/app/data` и сделай резервную копию SQLite и папки портретов.**

## Возможности

- Кнопочное меню Telegram: истории, свободные миры, персонажи, фотогалерея, сценические настройки, память и стиль.
- По кнопке «Начать» соавтор самостоятельно пишет первый пост; текущий игровой ход нельзя перегенерировать.
- Каждая история хранится в SQLite; фото — в постоянном каталоге `MEDIA_DIR`.
- Повествование теперь собирается прозрачным `PromptComposer`: короткие правила авторства, литературная манера, персонажи и канон, важные факты, старые найденные эпизоды, 1–3 стилевых образца, последние ходы, текущий пост.
- «🎨 Стиль и примеры»: присылай до 15 своих удачных постов (50–5500 символов), доступных в разных мирах. Для первой проверки в `prompts/examples.json` есть три небольших примера, предоставленных автором. События этих примеров **не являются каноном**.
- Встроенный полнотекстовый индекс **SQLite FTS5** по истории с изоляцией сессий; поиск работает без отдельного API и не заменяет закреплённую память.
- `/prompt` или «🔎 Промпт к модели» отправляет последний реально использованный запрос как TXT. Без перегенерации и дополнительных токенов API.
- `/backup` или «💾 Копия базы» отправляет согласованный снимок SQLite. Фото нужно сохранять отдельно.
- Нет отдельного обязательного сюжетного планировщика: модель напрямую пишет пост по выбранному контексту. Извлечение важных фактов после хода можно отключить `AUTO_MEMORY=false`.

## Быстрый запуск

Для локального запуска установите Python 3.11+, скопируйте `.env.example` в `.env`, заполните токены, затем:

```bash
pip install -r requirements.txt
python bot.py
```

В BotHost Pro выбирай Python и `bot.py` как точку входа. На первый запуск нового бота в `/app/data` с пустой базой потребуется временно указать `ALLOW_NEW_DATABASE=true` (затем убрать флаг). На существующем боте этого делать нельзя: должна подхватиться старая SQLite.

## Структура

- `bot.py` — обработчики постов, команд, перманентных действий.
- `interface.py` — кнопочное меню, карточки, фото, редактор примеров стиля.
- `storage.py`, `db_safety.py` — SQLite, консервативная миграция, снимки и поиск FTS5.
- `prompting.py`, `prompts/core.md`, `prompts/style.md`, `prompts/examples.json` — построение запроса.
- `engine.py`, `memory.py`, `vision.py` — генерация, факты и одноразовый анализ изображений.
- `tests/` — автономные тесты работы с базой и мок-ответами LLM.

## Защита приватности и ограничения

Доступ к Telegram-боту ограничен `OWNER_TELEGRAM_ID`. Не публикуйте `.env`, базу, фото и диагностические TXT — они могут содержать личные сюжеты и скрытые факты. API-провайдер применяет собственные правила обработки данных. Образцы не гарантируют качество художественного письма; итог проверяется живым тестом с доступным OpenAI API. Полный семантический RAG/эмбеддинги в этой версии **не реализованы**.

Важное: это самостоятельная Python-реализация общих идей слоистых промптов и лор-ретривала; исходный код SillyTavern не скопирован и не встраивается в проект.
